# Design Research Playbook

When designing screens, controls, or layout systems not explicitly detailed in the specification:

1. **Benchmark 2–4 Modern Reference Platforms**:
   - Linear, Raycast, Supabase, Duolingo, Anki/FSRS tools.
2. **Document Findings**:
   - Note interaction ergonomics, mobile responsive behavior, keyboard triggers, and visual hierarchy.
3. **Converge and Adapt**:
   - Adapt the industry-standard interaction pattern to LangFlow's dark-mode aesthetic.
