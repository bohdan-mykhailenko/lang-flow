# Linear Story & Issue Authoring

Structure user stories with:

1. **User Narrative**: "As a Bulgarian language learner, I want..."
2. **Acceptance Checklist**: Deterministic checkboxes for functionality.
3. **Technical Scope**: Crates, routes, database tables, and UI components impacted.
