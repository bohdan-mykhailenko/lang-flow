# New Document Procedure

1. **Category Folders**:
   - `specs/requirements/`: Product functional requirements.
   - `docs/standards/`: Engineering standards and checklists.
   - `docs/architecture/`: System design and diagrams.
2. **Naming Convention**:
   - Sequential prefix where relevant (`01-title.md`) or clear descriptive kebab-case.
3. **Index Maintenance**:
   - Always update the index in `AGENTS.md` or `docs/README.md` when introducing a new standard document.
