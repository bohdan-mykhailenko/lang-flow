Англійська мова — це **універсальна мова міжнародного спілкування та подорожей**. Мандруючи світом, ви зустрічатимете різні варіанти написання слів та місцеві назви, проте вас гарантовано зрозуміють у будь-якому куточку планети.

Нижче наведено практичні паралелі правопису й щоденної лексики, щоб ви впевнено орієнтувалися в аеропортах, готелях, закладах та бесідах з людьми з усього світу.

## ✍️ Поширені варіанти правопису

Більшість відмінностей у написанні слів підпорядковані чітким та передбачуваним закономірностям:

| Категорія / Суфікс | Варіант (US) | Варіант (UK) | Український переклад |
| :--- | :--- | :--- | :--- |
| **-or vs -our** | Color, Flavor, Favor, Neighbor, Honor | Colour, Flavour, Favour, Neighbour, Honour | Колір, Смак, Послуга, Сусід, Честь |
| **-ize vs -ise** | Organize, Realize, Recognize, Memorize | Organise, Realise, Recognise, Memorise | Організовувати, Усвідомлювати |
| **-er vs -re** | Center, Theater, Meter, Fiber, Liter | Centre, Theatre, Metre, Fibre, Litre | Центр, Театр, Метр, Волокно, Літр |
| **-ll- vs -l-** | Traveled, Canceled, Modeling, Labeled | Travelled, Cancelled, Modelling, Labelled | Подорожував, Скасований |
| **-se vs -ce** | Defense, Offense, Pretense, License | Defence, Offence, Pretence, Licence (іменник) | Захист, Образа, Ліцензія |
| **-og vs -ogue** | Dialog, Catalog, Analog | Dialogue, Catalogue, Analogue | Діалог, Каталог, Аналог |
| **Окремі слова** | Check, Gray, Pajamas, Tire | Cheque, Grey, Pyjamas, Tyre | Банківський чек, Сірий, Піжама, Шина |

## 🗣️ Поширені варіанти вимови

| Фонетична риса | Варіант (US) | Варіант (UK) |
| :--- | :--- | :--- |
| **Ротичність (звук 'R')** | **Ротична**: Звук /r/ чітко вимовляється завжди (*car* `/kɑːr/`, *hard* `/hɑːrd/`). | **Неротична**: Звук /r/ опускається після голосних (*car* `/kɑː/`). |
| **Flap 'T'** | Між голосними /t/ перетворюється на швидкий звук 'd' (*water* `[ˈwɑːt̬ɚ]`, *better* `[ˈbɛt̬ɚ]`). | Чіткий звук [t] або гортанне замикання (glottal stop [ʔ]). |
| **Широкий голосний A** | Відкритий плаский звук `/æ/` (*fast* `/fæst/`, *ask* `/æsk/`, *dance* `/dæns/`). | Глибокий задній звук `/ɑː/` (*fast* `/fɑːst/`, *dance* `/dɑːns/`). |
| **Літера Z** | Називається **Зі** (`/ziː/`). | Називається **Зед** (`/zed/`). |
| **Наголос у словах** | *AD-dress* (іменник), *GAR-age*, *CAFE*. | *ad-DRESS*, *GAR-idge*, *CAF-ay*. |
