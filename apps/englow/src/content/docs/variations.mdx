English is the **universal language of world travel and global communication**. As you travel the globe, you will encounter diverse spelling conventions and regional words, but you will be warmly understood everywhere.

Below is a practical guide to common spelling patterns and everyday vocabulary to help you navigate airports, hotels, cafés, and conversations anywhere in the world.

---

## ✍️ Common Spelling Patterns

The majority of spelling variations follow predictable patterns:

| Category / Rule | Variant (US) | Variant (UK) | Ukrainian Translation |
| :--- | :--- | :--- | :--- |
| **-or vs -our** | Color, Flavor, Favor, Neighbor, Honor | Colour, Flavour, Favour, Neighbour, Honour | Колір, Смак, Послуга, Сусід, Честь |
| **-ize vs -ise** | Organize, Realize, Recognize, Memorize | Organise, Realise, Recognise, Memorise | Організовувати, Усвідомлювати |
| **-er vs -re** | Center, Theater, Meter, Fiber, Liter | Centre, Theatre, Metre, Fibre, Litre | Центр, Театр, Метр, Волокно, Літр |
| **-ll- vs -l-** | Traveled, Canceled, Modeling, Labeled | Travelled, Cancelled, Modelling, Labelled | Подорожував, Скасований |
| **-se vs -ce** | Defense, Offense, Pretense, License | Defence, Offence, Pretence, Licence (noun) | Захист, Образа, Ліцензія |
| **-og vs -ogue** | Dialog, Catalog, Analog | Dialogue, Catalogue, Analogue | Діалог, Каталог, Аналог |
| **Specific words** | Check, Gray, Pajamas, Tire | Cheque, Grey, Pyjamas, Tyre | Чек, Сірий, Піжама, Шина |

## 🗣️ Common Pronunciation Varieties

| Phonetic Feature | Variant (US) | Variant (UK) |
| :--- | :--- | :--- |
| **Rhoticity (The 'R' sound)** | **Rhotic**: The /r/ is pronounced clearly (*car* `/kɑːr/`, *hard* `/hɑːrd/`). | **Non-rhotic**: The /r/ softens after vowels (*car* `/kɑː/`). |
| **The Flap 'T'** | Between vowels, /t/ sounds like a quick light 'd' (*water* `[ˈwɑːt̬ɚ]`, *better* `[ˈbɛt̬ɚ]`). | Crisp, aspirated [t] or a glottal stop [ʔ]. |
| **The Broad A** | Front flat vowel `/æ/` (*fast* `/fæst/`, *ask* `/æsk/`, *dance* `/dæns/`). | Deep back open vowel `/ɑː/` (*fast* `/fɑːst/`, *dance* `/dɑːns/`). |
| **The Letter Z** | Named **Zee** `/ziː/`. | Named **Zed** `/zed/`. |
| **Word Stress** | *AD-dress* (noun), *GAR-age*, *CAFE*. | *ad-DRESS*, *GAR-idge*, *CAF-ay*. |

## 🌍 English in World Travel

As you travel across continents, you'll hear colorful local expressions and friendly regional speech:

<div class="glide-card-grid">
  <div class="glide-card">
    <div class="glide-header">
      <span class="world-title">🦘 Australia (AU)</span>
      <span class="glide-arrow">Strine</span>
    </div>
    <p>Famous for high-rising friendly intonation and shortening almost every word with <em>-ie</em> or <em>-o</em>:</p>
    <ul style="padding-left: 1.25rem; font-size: 0.9rem; color: var(--sl-color-gray-2);">
      <li><strong>G'day mate</strong> = Hello friend</li>
      <li><strong>Brekkie</strong> = Breakfast</li>
      <li><strong>Arvo</strong> = Afternoon</li>
      <li><strong>Thongs</strong> = Flip-flops</li>
    </ul>
  </div>

  <div class="glide-card">
    <div class="glide-header">
      <span class="world-title">🏴󠁧󠁢󠁳󠁣󠁴󠁿 Scotland</span>
      <span class="glide-arrow">Scots / Gaelic Root</span>
    </div>
    <p>Distinguished by strong rolled/trilled 'r's and ancient poetic vocabulary:</p>
    <ul style="padding-left: 1.25rem; font-size: 0.9rem; color: var(--sl-color-gray-2);">
      <li><strong>Wee</strong> = Very small</li>
      <li><strong>Bonnie</strong> = Beautiful</li>
      <li><strong>Aye</strong> = Yes</li>
      <li><strong>Loch</strong> = Lake (with guttural [x])</li>
    </ul>
  </div>

  <div class="glide-card">
    <div class="glide-header">
      <span class="world-title">🇮🇪 Ireland</span>
      <span class="glide-arrow">Hiberno-English</span>
    </div>
    <p>Melodic, lyrical cadence that avoids rigid yes/no answers and uses rich social expressions:</p>
    <ul style="padding-left: 1.25rem; font-size: 0.9rem; color: var(--sl-color-gray-2);">
      <li><strong>Grand</strong> = Fine / Great ("I'm grand")</li>
      <li><strong>Craic</strong> = Fun, news, banter ("What's the craic?")</li>
      <li><strong>Ye</strong> = Plural you (you all)</li>
    </ul>
  </div>

  <div class="glide-card">
    <div class="glide-header">
      <span class="world-title">🇿🇦 South Africa</span>
      <span class="glide-arrow">SAE</span>
    </div>
    <p>Infused with Afrikaans, Zulu, and Xhosa roots, creating distinctive vocabulary and rhythm:</p>
    <ul style="padding-left: 1.25rem; font-size: 0.9rem; color: var(--sl-color-gray-2);">
      <li><strong>Howzit</strong> = Hello, how are things?</li>
      <li><strong>Braai</strong> = Barbecue</li>
      <li><strong>Bakkie</strong> = Pickup truck</li>
      <li><strong>Now-now</strong> = In a little while</li>
    </ul>
  </div>

  <div class="glide-card">
    <div class="glide-header">
      <span class="world-title">🏴󠁧󠁢󠁷󠁬󠁳󠁿 Wales</span>
      <span class="glide-arrow">Cymraeg Touch</span>
    </div>
    <p>Known for a sing-song intonation with melodic pitch jumps and heartfelt Welsh idioms:</p>
    <ul style="padding-left: 1.25rem; font-size: 0.9rem; color: var(--sl-color-gray-2);">
      <li><strong>Cwtch</strong> = A warm, affectionate cuddle/hug</li>
      <li><strong>Tidy</strong> = Great, proper, satisfactory</li>
      <li><strong>Lush</strong> = Wonderful or delightful</li>
    </ul>
  </div>

  <div class="glide-card">
    <div class="glide-header">
      <span class="world-title">🍁 Canada</span>
      <span class="glide-arrow">Canadian English</span>

    <ul style="padding-left: 1.25rem; font-size: 0.9rem; color: var(--sl-color-gray-2);">
      <li><strong>Washroom</strong> = Restroom / Bathroom</li>
      <li><strong>Toque</strong> = Warm winter knit beanie</li>
      <li><strong>Eh?</strong> = Tag question ("Nice weather, eh?")</li>
