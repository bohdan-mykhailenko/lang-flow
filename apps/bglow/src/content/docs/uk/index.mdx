## Структура болгарської звукової системи

У сучасній болгарській літературній мові виділяють **6 голосних звуків** та **39 приголосних фонем**, що позначаються 30 літерами:

  </Card>
  <Card title="Специфічні знаки" icon="warning">

## Головні фонетичні закони для українців

### 1. Редукція ненаголошених голосних (потъмняване)

Коли широка голосна перебуває в **ненаголошеному складі**, її вимова наближається до її вузької пари:

| Широка голосна | Ненаголошена вимова            | Приклад (правопис) | Літературна вимова | Український переклад |
| :------------- | :----------------------------- | :----------------- | :----------------- | :------------------- |
| **А**          | переходить у **[ъ]**           | _вода́_             | `[въда́]`           | вода                 |
| **О**          | переходить у **[у]**           | _прозо́рец_         | `[прузо́рец]`       | вікно                |
| **Е**          | зберігається (слабка редукція) | _зеле́н_            | `[зеле́н]`          | зелений              |

> ⚠️ **Правило перевірки:** Перевіряйте ненаголошену голосну формою під наголосом: _в**о́**ден_ → пишемо _в**о**да́_; _гр**а́**дове_ → пишемо _гр**а**дъ́т_.

---

### 2. Оглушення дзвінких приголосних наприкінці слів

В українській мові дзвінкі приголосні в кінці слова здебільшого зберігають дзвінкість (_дуб_, _хліб_, _сад_). У болгарській мові **дзвінкі приголосні наприкінці слова обов'язково оглушуються**:

```
Дзвінкі: [ Б ]  [ В ]  [ Г ]  [ Д ]  [ Ж ]  [ З ]  [ Дж ]  [ Дз ]
         ↕      ↕      ↕      ↕      ↕      ↕      ↕       ↕
Глухі:   [ П ]  [ Ф ]  [ К ]  [ Т ]  [ Ш ]  [ С ]  [ Ч ]   [ Ц ]
```

- _град_ вимовляється як **[грат]** (означає «місто»)
- _хляб_ вимовляється як **[хляп]** (означає «хліб»)
- _нож_ вимовляється як **[нош]** (означає «ніж»)

---

### 3. Секрет літери „Ъ“ (Ер голям)

На відміну від української мови, де цієї літери немає (а в російській це німий твердий знак), у болгарській мові **Ъ — це повноцінний голосний звук**:

- Звук `[ɤ]` — середній задній неогублений звук (схожий на ненаголошений український звук між [и] та [е], або румунський _ă_).
- Приклади: _б**ъ**лгарски_, _к**ъ**ща_, _п**ъ**т_, _с**ъ**н_, _в**ъ**прос_.
- В українських запозиченнях та відповідниках часто чергується з голосними або нулем: _ог**ъ**н_ (вогонь), _вят**ъ**р_ (вітер).
