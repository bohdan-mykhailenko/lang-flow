В болгарській мові особові займенники та дієслово-зв'язка **„съм“** (бути) є фундаментом мовлення. Головна відмінність від української: в болгарській мові дієслово „съм“ **ніколи не опускається** у теперішньому часі!

---

## 1. Особові займенники (Підмет — Хто?)

| Особа / Число        | Болгарською   | Вимова (IPA)                | Український відповідник | Приклад                                  |
| :------------------- | :------------ | :-------------------------- | :---------------------- | :--------------------------------------- |
| 1 ос. одн.           | **Аз**        | `[as]` _(оглушення в [с]!)_ | Я                       | _Аз уча български._ (Я вчу болгарську)   |
| 2 ос. одн.           | **Ти**        | `[ti]`                      | Ти                      | _Ти говориш бързо._ (Ти говориш швидко)  |
| 3 ос. одн. (ч.р.)    | **Той**       | `[tɔj]`                     | Він                     | _Той живее тук._ (Він живе тут)          |
| 3 ос. одн. (ж.р.)    | **Тя**        | `[tja]`                     | Вона                    | _Тя чете книга._ (Вона читає книжку)     |
| 3 ос. одн. (с.р.)    | **То**        | `[tɔ]`                      | Воно                    | _То спи спокойно._ (Воно спить спокійно) |
| 1 ос. мн.            | **Ние**       | `[niɛ]`                     | Ми                      | _Ние сме приятели._ (Ми друзі)           |
| 2 ос. мн. / ввічливо | **Вие / Вие** | `[viɛ]`                     | Ви / Ви                 | _Вие сте учител._ (Ви вчитель)           |
| 3 ос. мн.            | **Те**        | `[tɛ]`                      | Вони                    | _Те пътуват утре._ (Вони їдуть завтра)   |

> 💡 **Опущення займенника:** Оскільки дієслівні закінчення чітко вказують на особу, займенники _аз, ти, той..._ зазвичай опускаються, якщо на них не падає логічний наголос: _„Уча български.“_ замість _„Аз уча български.“_

## 2. Дієслово „СЪМ“ (Бути) у теперішньому часі

> ⚠️ **Типова помилка українців:** В українській ми кажемо _«Я лікар»_, _«Вона красива»_, _«Вони вдома»_. Болгарською це **груба помилка**! Потрібно обов'язково вживати зв'язку: _«Аз **съм** лекар»_, _«Тя **е** красива»_, _«Те **са** вкъщи»_.

| Особа             | Ствердження              | Заперечення         | Питання з часткою „ли“ |
| :---------------- | :----------------------- | :------------------ | :--------------------- |
| **Аз**            | съм `[sɤm]` (я є)        | не съм `[nɛ sɤm]`   | Студент ли съм?        |
| **Ти**            | си `[si]` (ти є)         | не си `[nɛ si]`     | Студент ли си?         |
| **Той / Тя / То** | **е** `[ɛ]` (він/вона є) | **не е** `[nɛ ɛ]`   | Студент ли е?          |
| **Ние**           | сме `[smɛ]` (ми є)       | не сме `[nɛ smɛ]`   | Студенти ли сме?       |
| **Вие**           | сте `[stɛ]` (ви є)       | не сте `[nɛ stɛ]`   | Студенти ли сте?       |
| **Те**            | **са** `[sa]` (вони є)   | **не са** `[nɛ sa]` | Студенти ли са?        |

### Заперечення в майбутньому часі: „Няма да...“

В болгарській мові майбутній час заперечується спеціальною незмінною часткою **„няма да“**:

- _Аз **няма да бъда** там._ (Я не буду там).
- _Ние **няма да закъснеем**._ (Ми не запізнимося).

## 4. Відмінки займенників: Прямий і Непрямий додаток

Оскільки в іменників відмінків немає, їхні залишки збереглися в займенниках. Вони бувають **повними** (для наголошення) та **короткими (клітиками)** (для звичайного мовлення):

| Особа  | Хто? (Підмет) | Кого? (Знахідний / Акузатив) | Кому? Чому? (Давальний / Датив)          |
| :----- | :------------ | :--------------------------- | :--------------------------------------- |
| 1 одн. | **аз**        | **мене** / **ме** (мене)     | **на мене** / **ми** (мені)              |
| 2 одн. | **ти**        | **тебе** / **те** (тебе)     | **на тебе** / **ти** (тобі)              |
| 3 ч.р. | **той**       | **него** / **го** (його)     | **на него** / **му** (йому)              |
| 3 ж.р. | **тя**        | **нея** / **я** (її)         | **на нея** / **ѝ** (їй) _(з наголосом!)_ |
| 3 с.р. | **то**        | **него** / **го** (його)     | **на него** / **му** (йому)              |
| 1 мн.  | **ние**       | **нас** / **ни** (нас)       | **на нас** / **ни** (нам)                |
| 2 мн.  | **вие**       | **вас** / **ви** (вас)       | **на вас** / **ви** (вам)                |
| 3 мн.  | **те**        | **тях** / **ги** (їх)        | **на тях** / **им** (їм)                 |

> ⚠️ **Літера „ѝ“ з наголосом:** Давальна клітика для неї пишеться обов'язково з наголосом — **ѝ**, щоб відрізняти від сполучника **и** (і/та): _„Дай **ѝ** книгата **и** тетрадката“_ (Дай **їй** книгу **і** зошит).

## 5. Закон Вакернагеля: Порядок клітик у реченні

Короткі займенники (_ме, те, го, му, ми, ѝ..._) та форми _съм_ є клітиками і **ніколи не можуть стояти першими в реченні**:

1. **Заборонено починати з клітики:**
   - ❌ _Съм лекар._
   - ✅ **Аз съм лекар.** або **Лекар съм.**
   - ❌ _Го видях._
   - ✅ **Видях го.** або **Вчера го видях.**

2. **Заперечення „НЕ“ притягує клітику на початок:**
   - ✅ **Не съм** готов. (Я не готовий).
   - ✅ **Не го** знам. (Я його не знаю).

3. **Дві клітики разом: спочатку Кому, потім Кого:**
   ```
   [ ДАВАЛЬНИЙ (Кому?) ]  +  [ ЗНАХІДНИЙ (Кого/Що?) ]
            ми                           го           →  „Той ми го даде.“ (Він мені його дав)
            ти                           я            →  „Ще ти я покажа.“ (Я тобі її покажу)
            му                           ги           →  „Купих му ги.“ (Я йому їх купив)
   ```
