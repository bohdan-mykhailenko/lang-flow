## Структура на българската звукова система

В българския книжовен език има **6 гласни звука** и **39 съгласни фонеми**, които се отбелязват с 30 букви:

  <Card title="6 Гласни звука" icon="star">
    Разпределени в три хармонични двойки широка/тясна гласна: **А — Ъ**, **О —
    У**, **Е — И**. Широките гласни се изговарят с по-широко отворена уста, а
    тесните — с по-стеснен звуков проход.
  </Card>
  <Card title="24 Съгласни букви" icon="pencil">
    Обозначават преградни, проходни и преградно-проходни звукове. Разделят се на
    звучни, беззвучни и сонорни.
  </Card>
  <Card title="Специфични знаци" icon="warning">
    **Ъ** е самостоятелен гласен звук; **Ь** няма звукова стойност сам по себе
    си (пише се само пред **О**); **Щ** е съчетание от два звука: `[шт]`.

    звук (`[йу]`, `[йа]`) или мекост на предходната съгласна.
  </Card>

## Основни фонетични закони на българския език

### 1. Редукция на широките гласни (потъмняване)

Когато широка гласна се намира в **неударена сричка**, тя се сближава по звучене със своята тясна двойка:

| Широка гласна | Неударен изговор            | Пример (правопис) | Книжовен изговор |
| :------------ | :-------------------------- | :---------------- | :--------------- |
| **А**         | преминава към **[ъ]**       | _вода́_            | `[въда́]`         |
| **О**         | преминава към **[у]**       | _прозо́рец_        | `[прузо́рец]`     |
| **Е**         | запазва се (слаба редукция) | _зеле́н_           | `[зеле́н]`        |

> ⚠️ **Правописно правило:** Не се подвеждайте по изговора! Проверявайте правописа с дума, в която гласната е под ударение: _в**о́**ден_ → пишем _в**о**да́_; _гр**а́**дове_ → пишем _гр**а**дъ́т_.

---

### 2. Обеззвучаване на звучните съгласни

Българските съгласни образуват корелативни двойки по **звучност / беззвучност**:

```
Звучни:    [ Б ]  [ В ]  [ Г ]  [ Д ]  [ Ж ]  [ З ]  [ Дж ]  [ Дз ]
           ↕      ↕      ↕      ↕      ↕      ↕      ↕       ↕
Беззвучни: [ П ]  [ Ф ]  [ К ]  [ Т ]  [ Ш ]  [ С ]  [ Ч ]   [ Ц ]
```

- **В абсолютния край на думата** звучните съгласни винаги се изговарят като своите беззвучни съответствия:
  - _град_ се изговаря като **[грат]**
  - _хляб_ се изговаря като **[хляп]**
  - _нож_ се изговаря като **[нош]**
- **Пред беззвучна съгласна** звучната съгласна се обеззвучава (регресивна асимилация):
  - _с**г**рада_ → [зграда] (озвучаване пред звучна)
  - _по**д**пис_ → [потпис] (обеззвучаване пред беззвучна)

---

### 3. Специфичната роля на „Ъ“ (Ер голям)

За разлика от руския език, където твердый знак (ъ) е разделителен знак без звукова стойност, в българския език **Ъ е пълноправен, изключително важен гласен звук**:

- Изговаря се като средна задна гласна `[ɤ]` (подобно на румънското _ă_ или шва в английското _b**ir**d_).
- Примери: _б**ъ**лгарски_, _к**ъ**ща_, _п**ъ**т_, _с**ъ**н_, _в**ъ**прос_.
- Често се редува с нула звук при словообразуване: _ог**ъ**н_ — _огни́_, _вят**ъ**р_ — _ветрове́_.
